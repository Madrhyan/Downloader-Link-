A powerful tool to download files from any direct URL using GitHub Actions.

## 🚀 نحوه استفاده

این پروژه به شما اجازه می‌دهد فایل‌ها را از طریق لینک مستقیم (Direct Link) و با استفاده از GitHub Actions دانلود کنید.

### 🛠 مراحل اجرا:

1. **مرحله اول: داشتن حساب کاربری**
   حتماً باید یک حساب کاربری در GitHub داشته باشید.

2. **مرحله دوم: فورک کردن پروژه (Fork)**
   روی دکمه **"Fork"** در بالای سمت راست صفحه کلیک کنید تا یک کپی از این پروژه در حساب خودتان ساخته شود.

3. **مرحله سوم: اجرای عملیات (Run Workflow)**
   - در ریپازاتوری خودتان، به تب **"Actions"** بروید.
   - ورک‌فلو را انتخاب کرده و روی **"Run workflow"** کلیک کنید.
   - لینک مستقیم (Direct Link) فایل را وارد و اجرا کنید.

4. **⚠️ مرحله بسیار مهم: دریافت فایل دانلود شده**
   - پس از اینکه عملیات (Workflow) تمام شد، باید به تب **Actions** برگردید.
   - روی آخرین اجرای موفق (Successful run) کلیک کنید.
   - در پایین صفحه، بخشی به نام **"Artifacts"** را مشاهده خواهید کرد.
   - روی فایل موجود در این بخش کلیک کنید تا فایل شما دانلود شود.

## 🇺🇸 English Instructions

A versatile tool to download files from direct URLs using GitHub Actions.

1. **Step 1: Account Required**  
   Make sure you have a valid GitHub account.
2. **Step 2: Fork this Repository**  
   Click the **"Fork"** button at the top right to create a copy in your account.
3. **Step 3: Run Workflow**  
   - Go to the **"Actions"** tab in your forked repository.
   - Select the workflow and click **"Run workflow"**.
   - Enter the **Direct URL** of the file you want to download.
4. **⚠️ Important: How to Download your File**  
   - Once the workflow finishes, go back to the **"Actions"** tab.
   - Click on the specific run you just completed.
   - Scroll down to the **"Artifacts"** section.
   - Click on the artifact to download your file.
